Transcribing a WhatsApp audio

Nov 24, 2026

Content note: this post describes a six-minute audio file downloaded from WhatsApp. No audio or transcript is reproduced here.

Preface

I wanted to see whether a chatbot could transcribe a six-minute voice note I'd downloaded from WhatsApp.

It's an ordinary task, not an adversarial one: a person has an audio file and wants the words in it. I tried the same file in four places — Meta AI, Mistral, ChatGPT, and Claude.

Preface to the chat

The file came straight out of WhatsApp as a six-minute audio recording. No special processing, no adversarial framing — just upload it and ask for a transcript.

Each assistant failed at a different point, and none of them produced a transcript.

Chat

There are no chat links for this one. The attempts never got far enough to be worth sharing: Meta wouldn't even let me select the file for upload, Mistral returned an error, and ChatGPT and Claude simply said they couldn't do it.

Notes

  1. Meta AI — I couldn't select the audio file for upload at all.
  2. Mistral — the upload went somewhere, but it produced an error.
  3. ChatGPT and Claude — both told me they didn't have the resources or drivers to do it.
  4. Zero transcripts from four attempts.

Reflection

This one isn't a safety story, it's a plumbing story. The failures were mundane — a file picker that wouldn't take the file, an error, and two assistants explaining they lacked the resources or drivers. That last phrasing is odd: it makes a missing capability sound like a broken machine on their end rather than a thing the product simply doesn't do.

Conclusion

A six-minute WhatsApp voice note defeated all four assistants. If the job is transcription, a dedicated transcription tool is the right answer; none of these chatbots could even get the file in the door.
